# PDF Fácil

Editor de PDF sencillo que funciona en el navegador. Tus documentos **no salen de tu ordenador**.

## Qué se puede hacer
- Cambiar el orden de las páginas arrastrándolas
- Quitar páginas
- Girar páginas
- Sacar unas páginas a un PDF aparte
- Deshacer cualquier cambio

Siempre se descarga una copia nueva; el PDF original no se modifica.

## Desarrollo

```bash
npm install
npm run dev      # abre http://localhost:5173
npm test         # tests
npm run build    # versión para publicar (carpeta dist/)
```

Cada push a `main` se publica automáticamente en GitHub Pages.
